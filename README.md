# Lab4 — DevOps Automation

Практическая работа по автоматизации развёртывания сервисов с использованием Bash, systemd и Ansible.

---

## Выполненные задачи

- создан bash-скрипт для запуска HTTP-сервиса;
- настроен `systemd` для автоматического запуска сервиса;
- реализован healthcheck для проверки состояния сервиса;
- подготовлен Ansible inventory;
- создан playbook для автоматизированного развёртывания сервиса.

---

## Проверка работы сервиса

```bash
curl http://127.0.0.1:8000
```

Команда позволяет проверить доступность HTTP-сервиса и убедиться в его корректной работе.
